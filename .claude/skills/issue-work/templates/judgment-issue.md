# 判断依頼テンプレート

人間の判断が必要になったときの本文フォーマット。用途は3つ:

- **撤退時の確認**(受け入れ条件が曖昧・設計判断が分かれる): 元 Issue への**コメント**として使う
- **マージ判断**: 無人モードの PR 作成後の**新規 Issue** として使う。タイトルは `[マージ判断] PR #<PR番号> <PRタイトル>`、本文の先頭にマーカー `<!-- merge-judgment-pr: <PR番号> -->` を必ず含める(PR クローズ時の自動クローズ用の目印)
- **見送り追認**(/ddd-review の suggestion 見送りなど): **新規 Issue** として使う

いずれも `needs-decision` ラベルを付与する。SKILL.md の「人間向け報告の執筆ルール」を必ず適用する。以下の `<!-- -->` は書き方の指示であり、出力には含めない。

---

     マージ判断の場合は「PR #<番号> をマージしてよいですか?」+ 判断材料の要約(1〜2文)。 -->

- **B: <選択肢>** — 同上
