## AT-504: 別銀行貯蓄残高の鮮度表示

- 目的: 手入力で更新する別銀行貯蓄口座の残高鮮度(最終更新から 35 日以上経過でアラート。OQ-44)が、残高画面と月次レポート画面の両方に表示されること
- 対象: `${WEB_URL}/balances`, `${WEB_URL}/reports`
- 実施者: 両方
- 前提条件: 別銀行貯蓄口座が 1 件以上登録済み(AT-102 完了)

| # | 操作 | 期待結果 | ☐ |
| --- | --- | --- | --- |
| 1 | 残高画面を開き、自分の別銀行貯蓄口座の行を確認 | 最終更新から 35 日未満なら「N日未更新」タグが出ない。35 日以上経過している口座には「N日未更新」タグが出る | ☐ |
| 2 | 月次レポート画面を開き「貯蓄残高の更新状況(現在)」を確認 | 自分の別銀行貯蓄口座ごとに最終更新日時が表示され、35 日以上経過した口座だけに「N日未更新」が付く | ☐ |
| 3 | 手順 1 と手順 2 の判定を突き合わせる | 同じ口座について 2 画面の鮮度判定(アラートの有無)が一致する | ☐ |
| 4 | 配偶者の別銀行貯蓄口座について、手順 2 のカードを確認 | 配偶者名義の口座は銀行名も更新状況も表示されない(残高は本人のみ可視 — P2-B5 / AT-404) | ☐ |
| 5 | SMBC 銀行・三井住友カード・NISA の行を確認 | いずれにも鮮度の表示は出ない(自動更新のため鮮度評価の対象外) | ☐ |
| 6 | 相手の実機で手順 1〜5 を実施 | 対称に同じ結果 | ☐ |

- 事後処理: なし(読み取りのみ)
- 備考: 依存 API `GET /api/dashboard/balance-freshness`。閾値 35 日は経過日数に依存するため、実施時点でアラート対象の口座が無い場合は手順 1・2 の「アラートが出ないこと」までを判定し、備考に「アラート未発生」と記録する(残高の手動補正 API が未実装のため、最終更新日時を任意に操作しての確認はできない — AT-9xx 昇格後に再実施)。残高一覧(手順 1)が AT-404 の可視範囲どおりに絞られていなかった不一致は #453 で解消済み(OQ-60。一覧は本人の口座のみ、配偶者分は合計 1 行)
