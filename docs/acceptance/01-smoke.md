## AT-002: LIFF ログイン → ダッシュボード表示

- 目的: 実機の LINE アプリから LIFF 起動 → LINE ログイン → 認証済みでダッシュボードが表示されること
- 対象: `${LIFF_URL}` → `${WEB_URL}/`
- 実施者: 両方(夫婦それぞれの実機)
- 前提条件: 許可リスト(HUSBAND/WIFE_LINE_USER_ID)に両者の LINE userID が投入済み

| # | 操作 | 期待結果 | ☐ |
| --- | --- | --- | --- |
| 1 | LINE アプリ内で `${LIFF_URL}` を開く | LIFF が初期化され、LINE ログインが自動実行される | ☐ |
| 2 | ログイン完了を待つ | エラーにならずダッシュボード(ホーム)が表示される | ☐ |
| 3 | 画面表示を確認 | 自分のロール(夫/妻)に応じた表示になっている(エラートースト・無限ローディングがない) | ☐ |
| 4 | アプリを一度閉じ、再度 `${LIFF_URL}` を開く | 再ログイン経由でも同様に表示される | ☐ |

- 事後処理: なし
- 備考: 認証は LINE ID トークン(Bearer)。API 側は JWKS 検証(`middleware/line-auth.ts`)。トークン期限切れ時の挙動も気になる場合は数十分放置後の再操作を追加確認

## AT-006: 通信できないときの失敗表示と再試行

- 目的: 電波の届かない場所で操作したとき、待ち続けずに失敗として伝わり、その場でやり直せること
- 対象: `${LIFF_URL}`(LINE 内ブラウザ。機内モードの再現が要るため実機のみ)
- 実施者: どちらか
- 前提条件: AT-002 合格。取込に使える明細 CSV または PDF を端末に用意しておく

| # | 操作 | 期待結果 | ☐ |
| --- | --- | --- | --- |
| 1 | LINE から LIFF を開き `/imports` を表示する | 取込画面が表示される | ☐ |
| 2 | 端末を機内モードにする | — | ☐ |
| 3 | 「CSV / PDF ファイルを選択して取込」から明細ファイルを選ぶ | 「変換中...」「アップロード中...」の表示で止まらず、「通信できませんでした。電波の良い場所で、もう一度お試しください。」が表示される | ☐ |
| 4 | 画面を確認する | 「もう一度アップロード」が表示されている | ☐ |
| 5 | 機内モードを解除し、「もう一度アップロード」を押す | 端末のファイル選択に戻らず、手順 3 で選んだファイルがそのまま送信され、取込結果が表示される | ☐ |
| 6 | 機内モードのまま `/`(ダッシュボード)を開き直す | 読込中の表示で止まらず、手順 3 と同じ文言で通信の失敗が伝わる | ☐ |

- 事後処理: 手順 5 で取り込んだ候補は、取込画面から取込ジョブを破棄するか、確定した場合は取引一覧から削除する(AT-301 の事後処理と同じ)
- 備考: 手順 3 は「一定時間で失敗になること」の確認であり、待ち時間そのものは判定に含めない。⚠ 端末によっては機内モードを OS が検知して LINE 側がエラー画面を出すことがある。その場合はアプリの表示に到達しないため NG とせず「LINE 側で遮断」と記録する
